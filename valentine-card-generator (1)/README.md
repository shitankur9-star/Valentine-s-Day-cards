# Valentine Card Generator ❤️

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Included

- React + TypeScript + Vite
- 6 card templates
- Live preview
- Message suggestions
- Surprise Me
- PNG / JPEG / PDF export
- Standard, Instagram, Story, Square and Print presets
- Web Share API
- Copy text and personalized card link
- localStorage persistence
- Responsive mobile layout

PDF export uses jsPDF. Image export uses html-to-image.
